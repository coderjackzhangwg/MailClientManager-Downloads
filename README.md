# 邮件客户端管理工具

**Windows 邮件阅读、本地归档与邮箱容量管理工具（即将提供免费 Beta 测试版）**

本项目的公开仓库用于**下载 Windows 安装程序、查看更新说明和反馈问题**。应用本身不是开源项目，本仓库不包含应用源代码。免费使用不等于开源授权。

## 下载

正式开放测试后，请到本仓库的 **Releases** 页面下载 Windows 安装程序。首次发布前需填写真实发行者与支持联系信息、发布法律文件、完成独立 Windows 测试。

- 安装包：以 `MailClientManager-Setup-*.exe` 为准（仅上传已审核的正式预发布构建）
- 校验：同一 Release 的 `SHA256SUMS.txt`
- 系统要求：Windows 10/11 64 位；不需要安装 Python

## 核心功能

- 连接获得授权的 Exchange EWS 或 IMAP/SMTP 邮箱（取决于服务商支持情况）
- 查看邮件、搜索及在本机保存邮件归档
- 估算邮箱邮件占用，生成并审核清理计划
- 通过后台托盘持续执行用户启用的同步任务
- 可以运行仅供本机使用的网页管理界面及实验性 IMAP/SMTP 网关

**重要：** 服务商和客户端兼容性存在差异。邮件本地归档默认不加密；服务器上的删除操作有风险，且可能不可撤销。企业邮箱用户必须事先确认自己具备导出、保存和删除邮件的权限。
